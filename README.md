
## Getting Started

### Build from Source

```bash
git clone https://github.com/Soflutionltd/PhotoPilot.git --recurse-submodules
cd PhotoPilot
npm install
npm start
```

You will need [Rust](https://www.rust-lang.org/tools/install) and [Node.js](https://nodejs.org/) installed.

---

## System Requirements

- **macOS** 13 (Ventura) or newer, optimized for Apple Silicon (M1/M2/M3/M4)
- **Windows** 10 or newer
- **Linux** Ubuntu 22.04+ or compatible

Recommended: 16 GB RAM minimum, dedicated GPU, SSD storage.
